# ProfilakSystem

Система подачи и рассмотрения заявок на заезды в профилакторий. Бэкенд на Java 21, Spring Boot и PostgreSQL, клиент на React.

## Бизнес-логика

Студенты выбирают заезд и подают заявку с документами. Сотрудники создают заезды, просматривают документы и принимают решения по заявкам. Одобрение резервирует место, если оно доступно. Студент может отметить свою одобренную заявку как оплаченную.

## Архитектура бэкенда

- `domain` содержит правила рассмотрения заявок и бронирования мест.
- `application` выполняет сценарии и обращается к БД, хранилищу документов и транзакциям через порты.
- `adapter` содержит HTTP-контроллеры, настройку сессий Spring Security, JDBC-реализации портов и локальное хранилище документов. Схемой PostgreSQL управляет Flyway.

## Локальный запуск

Нужны JDK 21, Docker Compose и Node.js. Из корня репозитория:

```bash
export PROFILAK_DB_PASSWORD='local-db-password'
export PROFILAK_STAFF_EMAIL='staff@example.com'
read -rs -p 'Local staff password: ' PROFILAK_STAFF_PASSWORD
echo
export PROFILAK_STAFF_PASSWORD
docker compose up -d
cd backend
bash ./gradlew bootRun
```

При первом запуске Flyway создаёт схему в чистой PostgreSQL, затем приложение создаёт учётную запись сотрудника из переменных окружения. Самостоятельная регистрация доступна только студентам с адресом `@g.nsu.ru`.

В другом терминале, из корня репозитория:

```bash
cd frontend
npm ci
npm start
```

[Клиент](http://localhost:3000) проксирует запросы на порт 8080. PostgreSQL по умолчанию доступен на порту 15434. Документы сохраняются в локальной папке `backend/uploads`, не входящей в репозиторий.
